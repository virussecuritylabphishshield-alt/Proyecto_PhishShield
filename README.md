# 🛡️ PhishShield

PhishShield es una plataforma web educativa contra el phishing. Analiza enlaces sospechosos, detecta dominios falsos y enseña a identificar correos fraudulentos con un verificador interactivo, consejos de seguridad y quiz. Creada para ayudar a navegar seguro en internet.

## 🚀 Cómo verla
1. Descarga el proyecto
2. Abre `index.html` con Live Server en VS Code

## 📁 Estructura
- `index.html` - Página principal
- `css/style.css` - Diseño
- `js/script.js` - Lógica del verificador
- `assets/` - Logos e imágenes
